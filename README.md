## About the Project

This website serves as a digital portfolio for my photography work.

The focus is on keeping the experience visual, clean, and straightforward. Photography remains the main element of the website, while the supporting content provides context about the work and the photographer.

The project also includes a private admin panel for managing portfolio content without having to modify the website manually.

## Features

- Photography portfolio and project galleries
- Individual project pages
- About and profile section
- Contact / connect section
- Responsive layout
- Private admin panel
- Portfolio content management
- Image upload and management

## Local Development

```bash
git clone https://github.com/ellenistanto/photography-portfolio.git
cd photography-portfolio
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```

## Deployment

The project is configured for deployment with Vercel.

The frontend is built with Vite, while the backend/API layer handles the application's dynamic functionality.

## Design

The design focuses on a minimal interface that keeps attention on the photography rather than the interface itself.
